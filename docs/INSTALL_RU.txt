GymBook 1.1 — установка и данные

ЧТО ЭТО
GymBook — офлайн-дневник тренировок и питания. Работает в браузере, интернет нужен
только для первой загрузки (потом приложение открывается офлайн).

БЫСТРЫЙ СТАРТ
1. Распакуйте архив в папку.
2. Откройте index.html — приложение запустится локально.
3. Для установки как приложения (PWA) нужен HTTPS-хостинг: Netlify, Cloudflare Pages,
   Railway, GitHub Pages или любой веб-сервер с сертификатом.

УСТАНОВКА КАК ПРИЛОЖЕНИЯ
Chrome / Edge (компьютер):
  Откройте адрес сайта → иконка установки в адресной строке или меню → «Установить GymBook».
Android (Chrome):
  Меню ⋮ → «Добавить на главный экран» / «Установить приложение».
iPhone / iPad (Safari):
  «Поделиться» → «На экран “Домой”».

ДАННЫЕ
- Тренировки, питание, вес и настройки хранятся только в этом браузере (localStorage).
- Сервер не получает и не хранит ваши данные.
- Очистка данных сайта или браузера удалит записи.
- Делайте резервную копию: ⚙️ → «Сохранить данные в файл». Файл JSON можно импортировать
  обратно на этом же или другом устройстве.
- Приложение просит браузер не удалять хранилище, но гарантировать это нельзя.

ОФЛАЙН
После первого открытия файлы приложения кэшируются. При отсутствии сети приложение
открывается и работает; изменения сохраняются локально.

ОБНОВЛЕНИЯ
При выходе новой версии внизу появится плашка «Доступна новая версия GymBook» с кнопкой
«Обновить». Нажмите её — приложение перезагрузится на новой версии. Данные сохранятся.
